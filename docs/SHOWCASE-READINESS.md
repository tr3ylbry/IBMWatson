### Rights Decisions

share-alike compliance; additional page-specific credit/third-party conditions
can apply. Current nine-source metadata is useful evidence, not clearance. For a
recording, include legible credits plus linked source/license notices with its
transcript; do not assume privately displayed UI attribution clears the final cut.
See [Wikimedia section7](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use#7._Licensing_of_Content)
and [CC BY-SA4.0 conditions](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en#s3).
CC licensing does not grant trademark/publicity rights; decide naming and
non-endorsement presentation separately, without inventing a requirement to buy
an artist license. No music, lyrics, album art or portraits were imported for this candidate.

[Stanford's license guidance](https://stanfordnlp.github.io/CoreNLP/#license)
describes full CoreNLP as GPLv3+ and proprietary distribution as requiring a
different license arrangement. Assess the actual code/model/dependency combination
and whether delivering binaries/source differs from operating a hosted service;
do not equate server use with automatically publishing all source, or assume
Apache Lucene makes the combined distribution Apache-only. No license was purchased.

The [official TriviaQA project](https://nlp.cs.washington.edu/triviaqa/) disclaims
ownership of underlying questions/documents; its preserved archive README restricts
use to non-commercial research, while the code repository says Apache2.0. Preserve
that unresolved tension and the [existing exclusion policy](EXTERNAL-CHALLENGE.md),
not a new blanket license interpretation. Keep benchmark question/context files
and historical coursework artifacts out of release/media bundles unless separately
cleared; explaining the project's origins and aggregate results is not distributing

## Operations and Accessibility

Current operations assume one always-running JVM, one local POSIX writer, stable
canonical config path, owner-only directories/files and cooperative atomic
replacement. Whole-state JSON writes serialize under one service lock;32MiB is a
fail-closed capacity bound, not a database. Two-hour expiry is absolute; lazy
pruning is not secure timed erasure. Clearing cookies loses ownership. Interrupted
searches become no-answer, not fresh guesses. See [durability contract](DURABLE-GAMES.md).
Do not use ephemeral serverless storage, autoscale replicas or a network filesystem
without new storage/ownership design and verification.

Planning assumption for a later invited pilot: at most five concurrent players,
20 new game sessions per two hours, one game each, no public topic-request intake.
That fits session counts absent abuse but is not yet an operational guarantee.
A five-client local burst completed25 rounds across five games:121 requests,
HTTP p50 16.1ms/p95 48.0ms/max114.3ms, no request errors or engine-unavailable rounds.
One post-burst RSS sample was116.6MiB with `-Xmx512m`; it is not peak memory or
an Internet load/capacity forecast. Costs were not estimated and no host selected.
Size/pricing evaluation follows workload and recovery decisions, using then-current
official prices; no service provisioning is authorized here.

Keyboard skip link, picker names/values/arrow/Enter selection, hint disclosure,
answer/next/completion/history focus, unavailable choices and reconnect were
